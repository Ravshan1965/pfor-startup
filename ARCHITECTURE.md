# Архитектура проекта ПФОР

## Принцип работы
- **Сервер:** Выполняет роль прокси-ретранслятора. Не производит тяжелых вычислений локально. 
- **Мозг:** Внешнее API (Claude API) по IP.
- **Инфраструктура:** 
  - Nginx (Reverse Proxy) - для приема запросов.
  - Python-скрипт - для передачи запроса в API и выдачи ответа клиенту.
  - UFW - закрытый контур.
- **Цель:** Исключить хранение весов моделей и тяжелых данных на диске сервера для сохранения скорости и стабильности.

## Технические требования
1. Не устанавливать тяжелые библиотеки (PyTorch, TensorFlow и т.д.) на сервер.
2. Весь код для обработки запросов должен использовать `requests` или `httpx` для связи с внешним API.
3. Логи только кратковременные, очистка по расписанию (если потребуется).
